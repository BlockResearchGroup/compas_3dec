    Solver¶

    ThreeDECAnalysis ¶

    Bases: Data

    Portable prepared input for a 3DEC analysis.

    The analysis is a serialisable snapshot. Runtime configuration such as an executable path or working directory belongs to :class:ThreeDECSolver and is intentionally excluded.

    from_blockmodel(model, problem) classmethod ¶

    Create a prepared analysis from a COMPAS DEM model and problem.

    The method uses public model/problem data wherever available, without retaining either complete object. The COMPAS graph node is deliberately reused as the 3DEC region number.

    Parameters:

    Name Type Description Default
    model BlockModel

    Source block model.

    		 required
    problem Problem

    Loads, supports, contact properties and solver options.

    		 required

    from_dem_problem(problem) classmethod ¶

    Create a prepared analysis from a refactored COMPAS DEM problem.

    In the current compas_dem API the model is a transient reference on Problem. When a complete compas_dem.models.Analysis is deserialised, it restores that reference before the problem is solved.

    ThreeDECBlockMaterial ¶

    Bases: Data

    Isotropic material assigned directly to 3DEC blocks.

    Parameters:

    Name Type Description Default
    density float

    Mass density in kilograms per cubic metre.

    		 required
    young_modulus float

    Young's modulus in pascals.

    		 None
    poisson_ratio float

    Poisson's ratio.

    		 None
    name str

    Material name.

    		 None
    Notes

    Rigid blocks use only density directly in the 3DEC input deck. Young's modulus and Poisson's ratio describe the source material and can be used to derive joint stiffness or future deformable-block properties.

    bind_gridpoints(node, gridpoints, tolerance=1e-06, overwrite=False) ¶

    Bind initial mesh vertices to 3DEC gridpoints by coordinates.

    This is the only geometry-based part of the identity mapping. Every match must be unique and within tolerance. The resulting gridpoint IDs are then persisted and used for all later result states.

    Name Type Description Default

    		 required

    		 required
    tolerance float

    Maximum initial coordinate distance.

    		 1e-06
    overwrite bool

    Permit replacement of an existing binding.

    		 False

    from_analysis(analysis) classmethod ¶

    Build initialisation, gravity, load and displacement stages.

    COMPAS DEM boundary-condition groups become sequential 3DEC stages in their registered order. Gravity is extracted into the mandatory first stage. A group containing both loads and prescribed displacements is split into a load stage followed by a displacement stage. Supports are read from the model during analysis preparation; prescribed zero translations are not reinterpreted as supports.

    Find a locally installed 3DEC executable.

    Parameters:

    Name Type Description Default

    Requested 3DEC version, for example "7.0" or "9.0".

    		 None
    search_roots sequence of path-like

    Installation roots to inspect instead of the platform defaults. Each path may be either an Itasca directory or its parent directory.

    		 None
